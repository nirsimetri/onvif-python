This glossary defines technical terms, abbreviations, standards, protocols, and concepts used throughout the ONVIF Python documentation.

## Standards and Organizations

**OASIS**
: Organization for the Advancement of Structured Information Standards.

**IEEE**
: Institute of Electrical and Electronics Engineers.

**RFC**
: Request for Comments.

**PKCS**
: Public-Key Cryptography Standards.

## Software Interfaces and Data Formats

**API**
: Application Programming Interface.

**CLI**
: Command-Line Interface.

**REST**
: Representational State Transfer.

**SOAP**
: Simple Object Access Protocol.

**XML**
: Extensible Markup Language.

**XSD**
: XML Schema Definition.

**WSDL**
: Web Services Description Language.

## ONVIF and Web Services

**XAddr**
: Endpoint Address.

**XAddrs**
: Endpoint Addresses.

**WS-Discovery**
: Web Services Dynamic Discovery.

**WS-Addressing**
: Web Services Addressing.

**WS-BaseNotification**
: Web Services Base Notification.

**WS-Security**
: Web Services Security.

**WS-UsernameToken**
: Web Services Security UsernameToken.

## Video Surveillance and Physical Security

**VMS**
: Video Management System.

**VSS**
: Video Surveillance System.

**NVC**
: Network Video Client.

**NVCs**
: Network Video Clients.

**NVT**
: Network Video Transmitter.

**NVD**
: Network Video Display.

**NVS**
: Network Video Storage.

**NVA**
: Network Video Analytics.

**MCS**
: Manufacturer Cloud Service.

**ACMS**
: Access Control Management System.

**BMS**
: Building Management System.

**PACS**
: Physical Access Control System.

**PSIM**
: Physical Security Information Management.

**REX**
: Request-to-Exit.

## Networking and Transport Protocols

**IP**
: Internet Protocol.

**IPv4**
: Internet Protocol Version 4.

**IPv6**
: Internet Protocol Version 6.

**TCP**
: Transmission Control Protocol.

**UDP**
: User Datagram Protocol.

**HTTP**
: Hypertext Transfer Protocol.

**HTTPS**
: Hypertext Transfer Protocol Secure.

**RTSP**
: Real-Time Streaming Protocol.

**RTP**
: Real-time Transport Protocol.

**SRTP**
: Secure Real-time Transport Protocol.

**WebRTC**
: Web Real-Time Communication.

**Unicast**
: One-to-one communication in which data is sent from one source to one destination.

**Multicast**
: One-to-many communication in which data is sent to a group of destinations.

**TTL**
: Time To Live.

**DHCP**
: Dynamic Host Configuration Protocol.

**DNS**
: Domain Name System.

## Time and Synchronization

**NTP**
: Network Time Protocol.

**UTC**
: Coordinated Universal Time.

**DST**
: Daylight Saving Time.

## Identifiers and Resource Addressing

**ID**
: Identifier.

**IDs**
: Identifiers.

**URI**
: Uniform Resource Identifier.

**URL**
: Uniform Resource Locator.

**URLs**
: Uniform Resource Locators.

**UUID**
: Universally Unique Identifier.

## Security Protocols and Cryptography

**TLS**
: Transport Layer Security.

**SSL**
: Secure Sockets Layer.

**JWT**
: JSON Web Token.

**RSA**
: Rivest–Shamir–Adleman.

**ECC**
: Elliptic Curve Cryptography.

**DER**
: Distinguished Encoding Rules.

**CA**
: Certificate Authority.

**CSR**
: Certificate Signing Request, also called Certification Request.

**CRL**
: Certificate Revocation List.

**CRLs**
: Certificate Revocation Lists.

## Device Management and Capabilities

**DP**
: Device Proxy.

**EQPreset**
: Equalizer Preset.

**PTZ**
: Pan/Tilt/Zoom.

**OSD**
: On-Screen Display.

**FW**
: Firmware.

## Media, Audio, and Video

**JPEG**
: Joint Photographic Experts Group.

**TTS**
: Text-to-Speech.

## AI and Tool Integration

**LLM**
: Large Language Model.

**MCP**
: Model Context Protocol.

**NL**
: Natural Language.

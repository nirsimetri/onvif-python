From official [PyPI](https://pypi.org/project/onvif-python/):
```bash
pip install --upgrade onvif-python
```
Or clone this repository and install locally:
```bash
git clone https://github.com/nirsimetri/onvif-python
cd onvif-python
pip install .
```

Once the installation is successful, you can also immediately access the [ONVIF CLI](core/onvif_cli.md) via the terminal using:

```bash
onvif --version
```
